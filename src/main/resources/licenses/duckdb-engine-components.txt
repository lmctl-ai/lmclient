DuckDB engine provenance and license inventory
==============================================

Source pin
----------

The bundled native DuckDB JNI engine is built from:

  repository: https://github.com/duckdb/duckdb-java
  commit:    a561d2ddadde231402411ce76112779bc34b57f0
  release:   v1.5.6.0

That exact checkout is recorded in deps.lock and scripts/build-duckdb.sh.
The complete upstream DuckDB MIT license is preserved in duckdb/LICENSE.

Standalone upstream license files
---------------------------------

The pinned tree contains one standalone license file:

  third_party/duckdb-java/LICENSE -> duckdb/LICENSE

The source tree has no separate top-level LICENSE/COPYING/NOTICE files for
the bundled subcomponents. Their source headers are therefore preserved
below as text notices instead of being replaced by a generic license label.

Header notice preservation
--------------------------

The ten duckdb/header-notices-*.txt resources preserve the first license and
copyright comment from each of 912 source/header files in the pinned
src/duckdb tree. Every entry records its original relative source path.
The inventory covers these source roots:

  extension/icu
  src/common
  src/include
  third_party/concurrentqueue
  third_party/fast_float
  third_party/fmt
  third_party/fsst

  third_party/hyperloglog
  third_party/jaro_winkler
  third_party/jemalloc
  third_party/libpg_query
  third_party/lz4
  third_party/mbedtls
  third_party/miniz
  third_party/pcg

This preserves copyright holders and the exact header terms supplied by the
pinned upstream source, including ICU's Unicode license and notices, zstd's
BSD terms, Mbed TLS's Apache/GPL alternatives, libpg_query notices, and the
individual permissive component headers. It does not copy source code.
